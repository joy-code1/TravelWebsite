Test mode — no real money moves. Card details are validated and never stored.

How to test this

  1. Start the backend: npm start (or PORT=8000 npm start) and open the site through http://localhost:4173.
  2. Book any trip on the Packages page — you will get a TRV-XXXXXX reference.
  3. Pay with card 4242 4242 4242 4242 (success) or any card ending 0002 (declined, HTTP 402).
  4. Check the booking with the reference + e-mail lookup or in /admin/ (Bookings tab).

Or from a terminal: curl -s -X POST localhost:4173/api/bookings -H 'content-type: application/json' -d '{"tripId":"bali","date":"2026-12-01","people":2,"name":"Test","email":"t@example.com"}'
